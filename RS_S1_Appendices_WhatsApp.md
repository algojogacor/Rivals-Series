# APPENDIX C — OFFICIAL LEAGUE TABLE

*Panduan klasemen resmi dan ringkasan aturan poin untuk pesan pembaruan klasemen:*

```text
==================================================
📊 RIVALS SERIES S1 — OFFICIAL LEAGUE TABLE
==================================================
Website Resmi: [URL ditambahkan setelah website tersedia]

KOLOM KLASEMEN RESMI:
• MP         : Matches Played (Total laga dimainkan, maks 20)
• W          : Wins (Menang = 3 poin)
• D          : Draws (Seri = 1 poin, hanya di MD1–MD10)
• L          : Losses (Kalah = 0 poin)
• GF         : Goals For (Gol memasukkan reguler + ET)
• GA         : Goals Against (Gol kemasukan reguler + ET)
• GD         : Goal Difference (Selisih gol = GF - GA)
• PTS        : Total Points
• ID Credits : Kredit Babak Indonesia (Progres per peserta dari target 5)
• Sanctions  : Pengurangan poin atau catatan disiplin aktif
• Status     : Status administratif hasil

KETENTUAN KHUSUS KLASEMEN:
1. Poin: Menang = 3 | Seri = 1 (MD1–MD10) | Kalah = 0.
2. MD11–MD20 wajib menghasilkan pemenang (ET & Adu Penalti aktif).
3. Gol adu penalti TIDAK dimasukkan ke GF/GA.
4. Skor administratif forfeit adalah 0–3 (masuk ke GF/GA tim, tanpa gol individual).
5. Technical Win dari undian digital: Menang 3 poin, tanpa gol fiktif (GF & GA tetap 0).
6. Kuota Indonesia: Wajib minimal 5 kredit babak sepanjang musim. Jika kurang, dikenai sanksi pengurangan 3 poin di akhir klasemen final (Pasal 19 Ayat 5).
==================================================
```
